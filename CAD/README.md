# KiCad Analog - Современный схемотехнический редактор

![KiCad Analog](https://img.shields.io/badge/version-1.0.0-blue)
![React](https://img.shields.io/badge/React-18.2.0-61dafb)
![TypeScript](https://img.shields.io/badge/TypeScript-5.2.2-3178c6)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-3.3.6-38bdf8)

Полнофункциональный аналог KiCad - профессиональное приложение для проектирования электронных схем с современным интерфейсом.

## 🚀 Возможности

### Основные функции
- ✨ **Редактор схем** - Интуитивный canvas для создания электронных схем
- 🎨 **Современный UI** - Темная тема с продуманным дизайном
- 📦 **Библиотека компонентов** - Обширная коллекция электронных компонентов
- 🔧 **Инструменты рисования** - Провода, шины, метки, узлы и многое другое
- 🎯 **Точное размещение** - Сетка с привязкой для точного позиционирования
- 🔍 **Зум и панорамирование** - Плавная навигация по схеме
- 📊 **Система слоев** - Управление различными слоями схемы
- 💾 **Экспорт/Импорт** - JSON, SVG, PNG форматы

### Компоненты

#### Пассивные компоненты
- Резисторы (R)
- Конденсаторы (C)
- Катушки индуктивности (L)
- Диоды (D)

#### Активные компоненты
- Транзисторы (NPN, PNP)
- MOSFET транзисторы
- Операционные усилители

#### Цифровые компоненты
- Логические элементы (AND, OR, NOT)
- Триггеры
- И многое другое

#### Источники питания
- Источники напряжения
- Источники тока
- Земля (GND)
- VCC

#### Соединители
- Разъемы (2-pin, 4-pin, 8-pin)
- Штыревые разъемы

## 🎮 Управление

### Горячие клавиши

#### Инструменты
- `V` - Выбор (Select)
- `W` - Провод (Wire)
- `M` - Перемещение (Move)
- `R` - Поворот (Rotate)
- `L` - Метка (Label)
- `J` - Узел (Junction)

#### Работа с объектами
- `Delete/Backspace` - Удалить выбранные объекты
- `R` (с выбранным объектом) - Повернуть на 90°
- `Escape` - Отменить текущее действие

#### Вид
- `Ctrl + G` - Переключить отображение сетки
- `Ctrl + Shift + G` - Переключить привязку к сетке
- `Ctrl + +` - Увеличить масштаб
- `Ctrl + -` - Уменьшить масштаб
- `Ctrl + 0` - Сбросить масштаб
- `Колесо мыши` - Изменить масштаб

#### Навигация
- `Средняя кнопка мыши` - Панорамирование холста
- `Клик по компоненту` - Размещение выбранного компонента

### Файлы
- `Ctrl + N` - Новый проект
- `Ctrl + O` - Открыть проект
- `Ctrl + S` - Сохранить проект

## 🛠️ Установка и запуск

### Требования
- Node.js 18+ 
- npm или yarn

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`

### Сборка для продакшена
```bash
npm run build
```

### Предварительный просмотр сборки
```bash
npm run preview
```

## 🔧 Разработка

### Добавление новых компонентов
1. Добавьте тип компонента в `ComponentLibrary.tsx`
2. Создайте функцию рисования в `canvasUtils.ts`
3. Обновите switch в `drawComponent()`

### Кастомизация темы
Измените цвета в `tailwind.config.js`:
```js
theme: {
  extend: {
    colors: {
      'dark-bg': '#1e1e1e',
      'dark-panel': '#252526',
      // ...
    }
  }
}
```
